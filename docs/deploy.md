# 公開のしかた（Cloudflare Pages）

公開先は Cloudflare Pages です。無料のプランで商用の利用（広告を載せること）が認められているため選びました（D0001）。
リポジトリに秘密を置かないように、GitHub との連携は Cloudflare の画面で人がつなぎます。つないだあとは、main に入るたびに自動で公開され、PR ごとに確かめ用の URL ができます。

## 人がすること（1回だけ）

1. Cloudflare のダッシュボードで、Workers & Pages → 作る → Pages → Git に接続 を選び、このリポジトリをつなぐ。
2. ビルドの設定を次にする。

| 項目 | 値 |
| --- | --- |
| フレームワーク | Astro |
| ビルドのコマンド | `npm run build` |
| 出力のフォルダ | `dist` |
| 本番の枝 | `main` |
| 環境変数 `NODE_VERSION` | `22.23.4` |
| 環境変数 `SITE_URL` | 独自ドメインが決まったら、その URL（例: `https://example.jp`）。決まるまでは入れない |

3. 独自ドメインを決めたら、カスタムドメインに足し、`SITE_URL` を入れて作り直す（サイトマップは `SITE_URL` があるときだけ作られます）。

## 公開のあとで人がすること

- 広告（AdSense など）とアクセスの計測を申し込む。申し込みの前に、プライバシーポリシーのページを載せる。
- 公開と main に入れること（merge）は、人がします。夜の実行は PR を作るところまでです。
